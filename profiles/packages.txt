# philosophy (tc-tiny not tc-full/cake, opkg stripped, USB/ipv6/tunnel modules

# hagezi-guncelle / /tmp-symlink mechanism entirely — configure the Hagezi Light
# list URL via LuCI after first boot (package's UCI schema changed recently
# upstream, a shipped static config risks a uci parse error, safer to set via
# the actual installed package's UI/defaults).
